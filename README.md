# TikSaver — تحميل فيديوهات تيك توك بدون علامة مائية

تطبيق أندرويد بسيط ومجاني لتحميل فيديوهات تيك توك **بدون علامة مائية** وبأفضل جودة متاحة (يفضل صيغة HD عند توفرها) وحفظها مباشرة في معرض الصور.

## التنزيل

- ملف الـ APK الجاهز موجود في: [`TikTokDownloader/dist/TikSaver.apk`](TikTokDownloader/dist/TikSaver.apk)
- أو حمّله من GitHub Actions (يُبنى تلقائيًا مع كل تعديل): تبويب **Actions** ← آخر تشغيل لـ `Build APK` ← **Artifacts** ← `TikSaver-APK`

## التثبيت

1. انقل ملف `TikSaver.apk` إلى هاتفك.
2. افتح الملف واسمح بـ "التثبيت من مصادر غير معروفة" عند الطلب.
3. التطبيق يدعم أندرويد 7.0 (API 24) وما فوق — لا يحتاج أي أذونات على أندرويد 10+.

## طريقة الاستخدام

1. افتح الفيديو في تطبيق تيك توك.
2. اضغط **مشاركة ← نسخ الرابط**.
3. افتح TikSaver، الصق الرابط في الحقل، اضغط **تحميل**.
4. الفيديو يُحفظ في: `Movies/TikSaver` داخل المعرض (بدون علامة مائية).

يمكنك أيضًا الضغط على **مشاركة ← TikSaver** مباشرة من داخل تيك توك، وسيبدأ التحميل تلقائيًا.

## كيف يعمل؟

يجرّب التطبيق ثلاث طرق بالترتيب حتى ينجح التحميل:

1. واجهة تيك توك الداخلية (`aweme/v1/feed`) عبر عدة سيرفرات — تعطي رابط الفيديو الأصلي بدون علامة مائية وأفضل جودة (bitrate الأعلى).
2. واجهة `tikwm.com` المجانية كبديل.
3. قراءة رابط التشغيل من صفحة الفيديو على الويب كملاذ أخير.

## البناء من المصدر

لا يحتاج المشروع Gradle ولا Android Studio. يكفي JDK 17 وأدوات build-tools 34:

```bash
TikTokDownloader/build.sh
```

يوجد أيضًا GitHub Actions workflow (`.github/workflows/build-apk.yml`) يبني الـ APK تلقائيًا عند كل تعديل.

## ملاحظة قانونية

هذا التطبيق مخصص للاستخدام الشخصي فقط. تحمّل المحتوى الذي تملكه أو الذي يُسمح بتحميله، واحترم حقوق أصحاب المحتوى. الاستخدام خارج ذلك قد يخالف شروط خدمة تيك توك.
